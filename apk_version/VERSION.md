# APK Version Release Log

## Version 1.2 (Version Code: 3)
- **File**: `IncomeControl-v1.2.apk` (and `app-latest.apk`)
- **Date**: October 1, 2026
- **Package**: `com.aistudio.incomecontrol.tkrzq`

### Features & Updates in v1.2 (+0.1):
1. **Zero Estimated / Planned Defaults**:
   - All categories (Rent, Sport, Alimentation, Water Bill, Electricity Bill, Internet Bill, Family) now start clean with `0.00 / 0.00 MAD` estimated/planned amount.
   - Total planned defaults to `0.00 MAD` matching Screenshot 2 (`com.homeneeds.home_needs`).
   - Planned remaining and actual remaining start aligned at `0.00 MAD` until you set your custom budget or log expenses.
2. **Simplified "Add Income" Dialog**:
   - Clean dialog with only the `MAD` amount field, Cancel, and Save (matching Screenshot 1).
3. **Category-Specific "Add Expense"**:
   - Quick logging on category cards in Wallet with `MAD` amount, helper note ("Added to this category's total spending"), and optional note (matching Screenshot 2).
4. **Clean Home Screen**:
   - All category filter pills removed from Home screen.
   - Home screen only displays separate purchases (water bottles, fast food, supermarket groceries) without category dropdown in the '+' dialog.
5. **Compact Monthly Spending Card**:
   - Scaled down total spent card for maximum visibility.
