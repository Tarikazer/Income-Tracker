# APK Version Release Log

## Version 1.1 (Version Code: 2)
- **File**: `IncomeControl-v1.1.apk` (also mirrored at `app-latest.apk`)
- **Date**: October 1, 2026

### Features & Updates in v1.1 (+0.1):
1. **Simplified "Add Income" Dialog**:
   - Clean dialog with only `MAD` amount field, Cancel, and Save (matching Screenshot 1).
2. **Category-Specific "Add Expense"**:
   - Quick logging on category cards (Rent, Sport, Bills, Family) with `MAD` amount, helper note, and optional note (matching Screenshot 2).
3. **Clean Home Screen**:
   - Filter pill section (`Rent`, `Sport`, `Alimentation`, etc.) removed from the Home screen.
   - Separate everyday purchases (water bottles, fast food, supermarket groceries) are tracked directly.
   - Home screen `+` FAB dialog streamlined with no category selection needed.
4. **Compact Monthly Spending Card**:
   - Scaled down total spent banner for better visibility on screen.
5. **Interactive Charts & Reports**:
   - Real-time calculations, category donut breakdown, daily spending timeline, and budget adherence.
